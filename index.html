📜 Grimoire Cheat Sheet: TOEFL Grammar

1. Noun Clause (Klausa Benda)
• Susunan wajib Statement (Connector + S + V), BUKAN bentuk tanya (what the theory is, bukan what is the theory).
• Sebagai Subjek kalimat selalu dianggap Tunggal (Singular Verb).
• Gunakan Whether (bukan If) jika berpasangan dengan "...or not".
2. Conditional Sentences (Kalimat Pengandaian)
• Type 1 (Future Real): If + S + V1, S + will + V1.
• Type 2 (Present Unreal): If + S + V2/were, S + would + V1.
• Type 3 (Past Unreal): If + S + had + V3, S + would have + V3.
• TOEFL Trap (Inversi tanpa 'If'): Had + S + V3 (Type 3) atau Should + S + V1 (Type 1).
